# Identidade Visual - MAEVE

## Direcao

A identidade do site combina azulejo portugues azul e branco com linguagem de convite editorial. A sensacao desejada e classica, luminosa, afetiva e refinada, sem parecer um template generico de casamento.

## Paleta Inicial

- Azul profundo: `#173B6C`
- Azul porcelana: `#5F86B6`
- Azul claro lavado: `#D8E4F1`
- Off-white papel: `#F8F3EA`
- Branco porcelana: `#FFFFFF`
- Dourado suave: `#B9975B`
- Verde folhagem discreto: `#496B4A`
- Tinta escura: `#1E2430`

## Tipografia

- Titulos: fonte serifada elegante, com aspecto de convite impresso.
- Textos: fonte sem serifa ou serifada simples, priorizando legibilidade.
- Assinaturas ou detalhes: uso pontual de fonte cursiva pode funcionar, mas deve ser discreto.

## Elementos Visuais

- Padrao de azulejo como elemento de abertura e detalhes de fundo.
- Molduras finas inspiradas em papelaria de casamento.
- Divisores ornamentais em azul ou dourado.
- Fotos do casal com tratamento natural, evitando filtros muito escuros.
- Flores brancas e folhagens como apoio visual, sem competir com o conteudo.

## Home

A Home deve abrir com uma animacao de mosaico/azulejos se revelando. Depois, o nome "MAEVE" aparece como elemento central, acompanhado de data, local e uma chamada para confirmacao.

## Secao MAEVE

A historia deve ser modular, permitindo adicionar capitulos depois. Cada capitulo pode ter:

- texto com foto lateral;
- foto grande;
- citacao;
- marco de data;
- pequena grade de imagens.

## Secao Casamento

Priorizar clareza. Data, horario, local e confirmacao precisam ser encontrados rapidamente. A estetica deve acompanhar o convite, mas sem esconder informacoes praticas.

## Lista De Presentes

A primeira versao usa Pix. A chave deve ter botao de copiar e espaco opcional para QR Code. O envio de comprovante e email fica para uma etapa futura.

## Restricoes Tecnicas

- Site estatico para GitHub Pages.
- Sem backend na primeira versao.
- Conteudo editavel por arquivo TypeScript em `src/data/siteContent.ts`.
- Fotos futuras concentradas em uma pasta previsivel.
